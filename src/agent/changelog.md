# Changelog

The agent changelog lives with the code, so it is never out of step with the
release you are running:

* [CHANGELOG.md](https://github.com/opensvc/om3/blob/main/CHANGELOG.md)

It covers the v2 to v3 migration prerequisites, the breaking changes to
commands, keywords and drivers, and the v3 enhancements.

If you are upgrading from v2.1, read the migration prerequisites **before**
installing v3: some of them have to be applied while still running v2.1.
